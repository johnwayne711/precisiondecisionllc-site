    HOW TO READ THIS VIEWOne edit can change many plotted moves.
    
                
              
    
              
    
                
    01
    What the count means
    0 differences means that many revised motion segments no longer match the original geometry. It does not mean that many separate code edits were made.
    
                
    02
    Why changes multiply
    A single X, Z, diameter, or profile edit can regenerate several G71 roughing passes, approaches, and retracts. Each affected plotted segment is counted.
    
                
    03
    How the colors work
    Gray still matches. Orange existed only in the original. Pink/red is new or altered in the revision. Short dashes mark unresolved paths without changing these colors; matching paths may still be unresolved.
    
                
    04
    How to verify it
    Start with Code audit to find the actual edited words, then use this view to inspect their geometric effect. Feed, speed, comment, or sequence changes may not change geometry.
    
              
    
              
    Important: G-Code Studio compares its modeled backplot. Canned cycles and machine behavior are approximations—not control-certified simulation or a substitute for approved prove-out.
