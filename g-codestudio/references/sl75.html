Spindle gear selection

CodeCommanded rangeG-Code Studio
M41First / lowContinues playback
M42SecondContinues playback
M43Third, where equippedReader models the command; confirm the installed variant

These meanings apply to the selected SL-75 environment. They do not enable these commands for other machine profiles or a conflicting Haas dialect.

The manufacturer prohibits gear changes under cutting load. Actual range speed limits belong to the machine’s spindle-output drawings. G-Code Studio does not know gear engagement, range RPM limits or shift duration, so gear-change time and later feed-per-revolution cutting time remain incomplete.

Use only one M word in a gear-selection block in this reader. A rapid/tool-selection block such as G00 T0101 M41 is supported, as shown in the manual. Combined M-word or feed-motion execution order is unconfigured. M40 neutral and other machine-specific M codes remain outside this gear-selection subset.

Source: Mori programming manual C-1 / C-3: SL-75 applicability and M-code list ↗; C-76 / C-77: ranges and programming example ↗.

The inch-profile fields use these metric values divided by 25.4. Physical X stroke is slide movement; diameter programming does not double it. Stroke lengths do not locate machine home, work zero or travel endpoints.

The brochure lists three spindle ranges for SL-75A and two for SL-75B/C. Do not assume a third range exists on every SL-75. The English reference separates these variants; opening it does not configure your machine.

Turning plane, units and X programming

The SL-75 environment starts in the X/Z turning plane (G18), with inch units and diameter-programmed X. These are explicit application settings for this setup. A program’s G17/G18/G19 selection overrides the starting plane; G20/G21 overrides the unit default.

Ordinary radius programming does not require adding G18 when the environment already establishes it. An unknown plane, an incompatible programmed plane or invalid arc geometry still needs review.

Reference: Mori programming manual B-12 / B-13 contains ordinary X/Z radius examples. Check the program and selected environment together.

Playback and review

M00 pauses the reader; Play resumes at the following block. M01 does so when Optional Stop is ON. M02/M30 ends the program and enables restart.

An unresolved command keeps playback at its blocking line. Play cannot silently rewind or execute beyond it. Step and the timeline can inspect any retained dashed PATH ONLY geometry; that preview does not restore timing, stock or clearance authority.

A T0302-style tool/offset pairing remains a separate review. Gear selection does not acknowledge a pairing or clear another warning.

What remains machine-specific

This environment remains a draft. The installed control, machine variant, gear speed limits, home and coordinate limits, offsets, installed options and actual machine qualification are not established by the documents here.

The linked programming manual is PM-NLTMSC518-I1EN, hosted by a third party. Its exact edition/control match to this older machine is unconfirmed. This reference distinguishes the implemented subset from the full manual; it does not claim full controller emulation.

Program text stays in G-Code Studio. Reference searches run locally, and source links contain no program data.
